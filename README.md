# AkiliNode Examples

Code examples for [AkiliNode](https://akilinode.com) — one API key for 25 AI models (DeepSeek, GLM and Qwen), priced for Africa. Top up with M-Pesa from USD 5. No subscription, no dollar card needed.

AkiliNode is OpenAI-compatible: if your code already works with the OpenAI API, you only change the base URL and the API key.

```text
base_url: https://api.akilinode.com/v1
```

## Examples

| Folder | What it shows |
|---|---|
| `python/` | Chat completion with the OpenAI Python SDK (one-line base URL swap) |
| `node/` | Chat completion in Node.js using plain `fetch` |
| `langchain/` | Using AkiliNode models in LangChain |
| `n8n/` | A ready-to-import n8n workflow: WhatsApp FAQ bot powered by DeepSeek |

## Get an API key

1. Sign up at https://akilinode.com/sign-up (you get USD 0.10 of test credit)
2. Create a token in the console
3. Top up from USD 5 — in Kenya, pay with M-Pesa by emailing support@akilinode.com for a redemption code

Full documentation: https://akilinode.com/docs

## Models

25 models including deepseek-flash, deepseek-v4-pro, glm-5.3, glm-4.7-flash (free), qwen3.7-max and more. Prices are below international list rates — see https://akilinode.com/pricing after signing in, or the model list in the docs.
